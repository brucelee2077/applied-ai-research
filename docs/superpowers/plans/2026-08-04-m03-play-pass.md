## ⚠️ Five verified traps — read before touching anything

Each was reproduced against the real tree, not inferred.

1. **`src=` must be UNQUOTED.** `visual_integrity_gate.py:84` is
   `re.findall(r'%%%\s*viz\s+src=(\S+)', src)`. `\S+` swallows quotes, so
   `src="../../viz/x.html"` captures the quotes too → `FAIL viz embed points at a MISSING file`
   → exit 4, even though the file exists. Reproduced. Quote `title=` and `caption=` only.
2. **Exactly one space after `%%%`.** `%%%viz` and `%%%  viz` satisfy `visual_integrity_gate`
   but `reader_flow_gate.py:66` matches the literal substring `'%%% viz'` and reports
   `concept cN has NO visual` → exit 2.
3. **Never omit `src=`.** `render_viz` defaults it to `''` (`v8lib.py:226`) and emits
   `<iframe src="">`, which passes **every gate at exit 0** — a silent blank widget.
4. **The write happens BEFORE the gate verdicts.** Verified at `compile_lesson.py:111-121`:
   the file is written, *then* `if not sok: sys.exit(3)` and `if not vok: sys.exit(4)`. So
   exits 3 and 4 leave a gate-failing `lesson.html` on disk. **After any non-zero exit other
   than 2, run `git checkout sessions/m03-attention/<day>/lesson.html` before retrying.**
5. **A dependency on uncommitted work.** `sessions/_compiler/gates/concept_shell_gate.py` has
   an **unstaged** modification from a concurrent session (6 added lines) that scopes the
   quiz-question count to the quiz section so `%%% warmup` no longer over-counts. All 5 m03
   days have a `%%% warmup`, so this fix is load-bearing for every compile here. Do not revert
   it, do not commit it (it is not ours), and if compiles start failing at exit 3 on a quiz
   count, check whether it is still present.

**Baseline, verified:** all 5 m03 days currently recompile **byte-identical** to their
committed `lesson.html`. So any diff after an edit is attributable solely to that edit.

## Per-lesson compiler procedure

```bash
# 1. edit source.md by hand — NEVER lesson_build.js (that is the ~$300/day LLM loop)
# 2. compile (free, offline, ~0.12s, deterministic)
python3 sessions/_compiler/compile_lesson.py sessions/m03-attention/<day>/source.md
# 3. the gate the compiler does NOT run (lesson_build.js normally does)
python3 sessions/_compiler/gates/concept_structure_gate.py sessions/m03-attention/<day>/source.md
# 4. post-checks
grep -c 'iframe src=""' sessions/m03-attention/<day>/lesson.html   # must be 0
git diff --stat sessions/m03-attention/<day>/lesson.html
```

Success looks like:
```
-- Visual Integrity Gate --
   pass viz file exists: ../../viz/<name>.html
   pass   viz ../../viz/<name>.html has a matching height-sender ('viz-height')
wrote lesson.html (NNNNN chars)

OK — compiled and all gates pass.
```

| exit | gate | lesson.html written? | meaning |
|---|---|---|---|
| 0 | — | yes | all pass |
| 2 | Reader Flow | **no** | concept lost its visual, or the `%%%viz` whitespace bug |
| 3 | Concept Shell | **YES — revert it** | quest-id changed, concept lost visual/gotit, quiz count |
| 4 | Visual Integrity | **YES — revert it** | missing viz file (or quoted `src=`), or sender mismatch |

## Phase A — five standalone viz pages (independent, parallelisable)

Each is a new self-contained file touching no lesson, so nothing can break. House pattern:
copy the chrome from `sessions/viz/embedding-similarity.html` (the newest page and the only one
authored as an inline-lesson companion — notably it ships **zero nav links**, because a
`../index.html` back-link inside a Toy Shelf panel loads the whole hub into the small iframe).

Every page must: be plain SVG with **no `<script src=`** (d3 is unnecessary for fixed grids and
would add a dep-existence check); carry the `viz-height` sender IIFE verbatim; keep Reader-A
register; and satisfy the §4.2 bar — **you can break it**.

Keep the Google Fonts `<link>` tags. All 22 existing pages have them; they 403 in this
environment and fall through to the local stack via `var(--body)`. Consistency beats a
micro-optimisation.

- [ ] **A1 — `sessions/viz/positional-collide.html`** (the only genuinely new widget)

  Mechanism, in the lesson's own words (`day-05-positional/source.md:181`): *"seat 5 and seat 6
  would read almost the same value and **collide**"* … *"seat 2 and seat 40 might land on the
  same value and collide too."* The lesson **states** the collision and never lets the learner
  cause one. This widget does.

  Fixed 12-seat sentence (two `the`s give a built-in identical-word probe):
  `the(0) grey(1) cat(2) chased(3) the(4) small(5) brown(6) dog(7) down(8) our(9) quiet(10) street(11)`

  Controls, all on `input`: `pc-waves` (1–4, default 4) · `pc-lam` base wavelength λ₀ in **seats**
  (default 2π ≈ 6.28) · `pc-spread` checkbox (default on).

  Maths — `P` waves, `d = 2P` slots, `B` = 10000 when spread on else 1,
  `λᵢ = λ₀ · B^(i/P)`, slot `2i` = `sin(2π·pos/λᵢ)`, slot `2i+1` = `cos(2π·pos/λᵢ)`.
  Gap = `min over a<b of max over k of |stamp[a][k] − stamp[b][k]|` (Chebyshev) — the same
  metric as `day-05-positional/experiment.py:85`.

  Render a 12×8 heatmap (row = seat, labelled with its word), 3 readouts, one verdict line.
  Build the 96 `<rect>` once at init; `draw()` only re-sets `fill`. Never `innerHTML` in `draw()`.

  Verdict thresholds: gap ≥ 0.25 → `Every seat has its own fingerprint ✓`; 0.05–0.25 → nearly
  twins; < 0.05 → `COLLIDED — seat A and seat B now carry the SAME stamp. Order is lost again.`
  Outline the guilty pair in red; under 0.005 also print both stamp rows as numbers.

  Four presets (**mandatory** — at 4 waves with spread on, the first collision only appears near
  λ₀ ≈ 99, so a learner may never find a break unaided): `the real Transformer` (4 / 6.2832 / on)
  · `just one wave` (1 / 4.0 / on) · `all waves the same speed` (4 / 4.0 / off) · `waves far too
  slow` (4 / 256 / on).

  **Verification — these numbers were recomputed independently and must reproduce:**

  | preset | gap | colliding pair |
  |---|---|---|
  | real Transformer | `0.4240` | small@5 & street@11 |
  | just one wave | `0.0000` | cat@2 & brown@6 (rows 0/4 also identical — the two `the`s) |
  | all same speed | `0.0000` | cat@2 & brown@6 |
  | far too slow | `0.0237` | quiet@10 & street@11 |

  Also: at P=4, λ₀=2π, spread on, **seat 1 must equal**
  `[0.8415, 0.5403, 0.0998, 0.995, 0.01, 1.0, 0.001, 1.0]` and the 6-seat gap must be `0.7682` —
  both byte-matching `day-05-positional/expected_output.txt` lines 33 and 39. This is the
  strongest available check that the widget agrees with the lesson's own Produce artifact.

  Structural precedent: `sessions/viz/leaky-slope.html` — `mk()`/`add()` `createElementNS`
  helpers, build-once/mutate-attributes `draw()`, preset buttons, and a readout that flips a
  **verdict word** on a threshold. ⚠️ It is **untracked** and in `_shelf_audit.py` `EXCLUDED` —
  copy its shape, never reference it.
