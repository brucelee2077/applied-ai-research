Module 11 · Scale · Day 1

One-VariableAblations

You changed two things in your model and the score went up. Great — but which change did it? You cannot know. This is the most common way research goes wrong. The fix is simple and strict: change ONE thing at a time, and always keep an honest baseline to compare against. Get this right and every result you report becomes trustworthy.

🎯
By the end, you'll be able to: explain why changing two things at once cannot tell you which one mattered, set up a clean one-variable ablation against a fixed baseline, and spot a confounded experiment when you see one.
1Change one thing, keep everything else fixedWhat is it
🧭
What this assumes: you have trained a model and read a score like accuracy or loss (from M1 and M2). Today is not about the model. It is about how you run a test so the number you get actually means something.

The trap

You want to improve your model. So you make it bigger AND you train it longer. The score goes up by 2%. You are happy. But now a friend asks: was it the bigger model, or the longer training? You have no answer. You changed two things, so the result is stuck to both of them. This mess has a name: a confounded experiment. The word "confound" means "to mix up so you cannot tell apart".

The fix: an ablation

An ablation is a test where you change exactly ONE thing and freeze everything else. If the score moves, it moved because of that one thing. Nothing else could have caused it. This is the whole idea, and it is powerful because it is so simple.

You always need a baseline

To say "this change helped", you need something to compare against. That reference run is your baseline. It uses your normal settings and you do not touch it. Every new run is measured against this same honest baseline — never against your memory of an old number.

The rule in one line

Freeze everything, change one variable, compare to the baseline. That is a clean controlled experiment. Do it and your results become trustworthy. Skip it and your results are just guesses wearing a lab coat. Keep going 👇

2A taste test where you change only the saltIntuition
🥘
Two soups

You cook a soup. It tastes fine. You want it better, so you add more salt AND more pepper, then taste again. It is better! But is it the salt or the pepper? You cannot tell. You changed two things, so the "better" is glued to both.

🧂
The clean test

Do it right: cook two bowls from the same pot. Bowl A stays as it is — the baseline. Bowl B gets only more salt, nothing else. Now if B tastes better, it was the salt. One change, one clear answer.

In one line: an ablation is a taste test where you keep everything the same except the one ingredient you are curious about, so the difference in taste points straight at that ingredient.

Your model is the soup. The baseline is the plain bowl you never touch. Changing "just the salt" is changing one setting — a bigger model, or more training, but never both at once. Then the taste (the score) tells you what that one change did.

⚠️
Where the analogy breaks: with soup you taste right away and it never changes on its own. A model has luck baked in — run it twice and the score wobbles a little even with no change. So one soup-tasting is enough, but one model run may not be. You will fix that on Day 2 with random seeds.

4The delta, worked out by handMechanism & why

Step 1 — in plain words

Run the baseline and write down its score. Then change one thing, run again, and write down that score. The delta is just the gap between the two: how much better (or worse) your change made things. If only one thing changed, the delta belongs entirely to that thing.

Step 2 — the formula

🧮
Δ = score(changed) − score(baseline)
# Δ (delta) = the improvement from your one change

Symbols: score(baseline) = the number your untouched reference run got. score(changed) = the number after you changed one thing. Δ (the Greek letter delta) = the difference. A positive Δ means the change helped; a negative Δ means it hurt.

Step 3 — a worked example

Say your baseline model gets 82.0% accuracy. You change ONE thing — a larger hidden size — and it gets 83.5%.

🔢
score(baseline) = 82.0%
score(changed) = 83.5% # only hidden size changed

Δ = 83.5 − 82.0 = +1.5% # this gain is from the bigger hidden size

Because only the hidden size moved, the +1.5% points straight at it. Now compare the broken version: if you had ALSO trained longer, the same +1.5% could be from the size, the extra training, or both. The delta would still be +1.5%, but it would mean nothing.

Why this is a big deal

  • The delta is only clean when one thing changed: confound the run and the delta becomes un-readable, even though the arithmetic looks the same.
  • The baseline must stay fixed: if you quietly change the baseline too, you are comparing against a moving target and the delta lies.
  • Two changes need two experiments: to test size AND training length, run one ablation for each, so each delta is clean.
🔗
The big picture: every honest research paper is a stack of clean deltas. "This trick adds +0.8%, that trick adds +0.5%." Each number comes from one ablation against one fixed baseline. Break that discipline and the whole result collapses. This is the foundation for the rest of the module — and the paid capstone.
