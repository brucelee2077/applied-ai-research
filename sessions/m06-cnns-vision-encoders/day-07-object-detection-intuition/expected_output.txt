  iou(cat_true, cat_pred) = 0.7176
  cat_true vs dog:      overlap rect (300, 200, 150, 140) -> width -150 and height -60 are NEGATIVE, both clamped to 0
  iou(cat_true, dog)      = 0.0
  pixel grid shape: (320, 400) (rows = y, cols = x) — counted pixel by pixel, shared = 7650  together = 10660  ratio = 0.7176
