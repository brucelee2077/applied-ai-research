Many looks at once

One attention can only track one kind of relationship at a time. Real transformers split the vector into several heads — each does its own attention on a thinner slice, so one head can track subject→verb while another tracks pronoun→noun. Slide the number of heads and watch the vector split and the patterns multiply.

What to notice

  • Each head gets a distinct grid. With several heads, one can track “look back at the subject,” another “look at the next word,” another “stay on yourself.” One head could never do all three at once.
  • More heads means thinner slices: d_k = d_model ÷ heads shrinks. The total width is unchanged — you are reshaping the same vector, not adding parameters.
  • The heads are recombined by concatenating their outputs and multiplying by one matrix W_O, which lets the model mix what the different heads found.
One trap to avoid
Heads do not each run on the full vector. The d_model dimensions are divided among the heads, so 8 heads on a 512-wide model means each head works in a 64-wide space. More heads ≠ more total compute here — it is the same width, sliced.
Quick check (3 questions)
1. Why use more than one attention head?
So the model can track several kinds of relationships at once — each head learns its own attention pattern (e.g. one for pronoun→noun, one for verb→subject).
2. If d_model = 512 and there are 8 heads, what is d_k per head?
64 (512 ÷ 8). The vector is split, so each head works in a smaller subspace.
3. How are the heads recombined into one output?
Concatenate the per-head outputs back to d_model, then multiply by the output matrix W_O to mix them.
