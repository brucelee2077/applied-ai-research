The Roofline Model

What am I looking at? The roofline model shows the fastest speed a kernel can reach on a chip, given how much math it does per byte of memory it moves. If it moves too many bytes for too little math, memory bandwidth caps it (the sloped roof). If it does plenty of math per byte, raw compute caps it (the flat roof).

What to notice

  • The kernel sits at attainable = min(peak_compute, intensity × bandwidth). Left of the ridge it is memory-bound (the sloped roof, limited by loading bytes); right of the ridge it is compute-bound (the flat roof, limited by raw FLOPs).
  • The ridge point is intensity_ridge = peak_compute / bandwidth. Most LLM decode lives far to the left of it: each token reloads all the weights but does little math per byte, so it is bound by weight loading, not compute.
  • Raising arithmetic intensity — bigger batch, kernel fusion, FlashAttention — moves the dot right toward the compute roof, where the expensive silicon is actually used.
