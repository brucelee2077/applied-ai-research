FlashAttention: Tiling to Beat the Memory Wall

Attention normally builds a full N×N score matrix and parks it in slow GPU memory (HBM). FlashAttention never writes that matrix down: it walks the scores in small tiles kept in fast on-chip memory (SRAM) and keeps a running softmax. Same math, far less memory traffic. Flip between the two modes below and watch the memory cost change.

Controls

note FlashAttention is exact, not an approximation. It computes the identical softmax·V output as standard attention. It only reorders the work to be IO-aware — the online softmax lets it fuse the whole computation into one pass over tiles, so the N×N matrix is never materialized.

What to notice

  • The N×N matrix is the villain: standard attention pays O(N²) HBM traffic and allocates an N×N buffer, so cost explodes as N grows.
  • Tiling + online softmax keeps every intermediate in SRAM. Flash reads K and V about N/B times but never writes the score matrix — traffic drops toward the O(N·d) cost of just moving Q, K, V, O.
  • Same exact result, far less HBM traffic and memory. The win comes from being IO-aware, not from dropping any computation.
