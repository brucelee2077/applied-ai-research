What to notice

  • DP replicates — dead simple, but every GPU carries a full copy of the model, so it wastes memory and can't fit a model larger than one device.
  • FSDP shards weights, gradients, and optimizer state so a huge model fits, at the cost of extra AllGather / ReduceScatter traffic every layer.
  • TP splits inside a layer — low latency and great for one big matmul, but it AllReduces activations constantly, so it demands a fast interconnect (NVLink) and stays inside one node.
  • PP splits across layers — cheap point-to-point comms, but the startup/drain bubble wastes time unless microbatches ≫ stages. Real training composes several of these at once (3D / 4D parallelism).
