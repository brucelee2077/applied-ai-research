Scaling Laws: IsoFLOP Parabolas & the Chinchilla Frontier

A scaling law predicts model loss from two knobs: parameter count N and training tokens D. Training compute is fixed at C = 6·N·D FLOPs. For each compute budget there is one best way to split it between a bigger model and more data. This page lets you find that split.

What to notice

  • Each colored curve is one fixed compute budget. It is a parabola in log N: too few params (left) wastes compute on data; too many params (right) starves the model of tokens. There is exactly one best N at the bottom — the compute-optimal point N*.
  • Joining the minima across budgets draws the compute-optimal frontier. It is a straight line in log-log space, so N* ∝ Cβ/(α+β) — a power law. When α ≈ β, N* and D* grow at the same rate (both ∝ √C): the Chinchilla result of ~20 tokens per parameter.
  • The orange dot is a Kaplan-style choice: too many params, too few tokens. It sits up the right wall of the parabola — same compute, higher loss. Kaplan (2020) over-weighted N; Chinchilla (2022) showed N and D should scale together.
