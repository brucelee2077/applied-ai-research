Module 5a · Represent · Day 1

The HighwayAround the Town

A deep network stacks many layers. Each layer changes the numbers a little. After 20 or 50 layers, the first signal is almost gone — and the gradient that should update the early layers fades to nothing. Today you learn a one-line fix that keeps both the signal and the gradient alive: add the input back. It is called a residual connection, and every deep transformer depends on it.

🎯
By the end, you'll be able to: explain what a residual (skip) connection is, write output = sublayer(x) + x, and say why adding the input back lets gradients flow through very deep stacks.
1A shortcut that adds the input backWhat is it
🧭
What this assumes: you know a neural network is a stack of layers, and each layer does some math on its input (M4). You do not need any transformer parts yet. This is the first brick of the transformer block.

The problem: deep stacks forget

Stack many layers and a problem appears. Each layer reshapes the numbers a little. After many layers the original signal is buried, and the gradient — the signal that tells early layers how to improve — shrinks toward zero. Early layers stop learning. People call this the vanishing gradient problem.

The fix in one line

A residual connection (also called a skip connection) is tiny. After a layer processes the input x, you add the original x back:

🧮
output = sublayer(x) + x

The word residual means "what is left over". The layer no longer has to reproduce the whole answer. It only has to learn the small change, the leftover, to add on top of x.

Why it matters

With this one addition, the signal always has a clean path from start to end. Even if a layer learns nothing useful, the output is at least as good as the input, because the input is added back. This single trick is what let networks grow from a few layers to hundreds. Keep going 👇

😕
为什么这里容易卡住 · Why this trips people up: "就加一个 x" 看起来太简单，不像能解决大问题。In plain terms: adding the input back looks trivially small — how can one + x matter? The payoff is not in the forward pass; it is in the backward pass, where that +x becomes a +1 that gives the gradient a road home which never multiplies to zero.
2A highway that bypasses a busy townIntuition
🛣️
The bypass highway

Imagine a road that must cross a busy town. The slow way winds through every street (the layer). The fast way is a highway that goes straight around it. A residual connection is that highway: the input skips past the layer and rejoins on the other side.

🔧
The layer only fixes small things

Since the input already arrives safely by the highway, the town road does not have to carry everything. It only adds the local repairs — the small change the layer learned. Less work, and nothing important gets lost.

In one line: the input takes a fast lane straight to the output, and the layer just adds a small correction on top.

直觉 / Intuition: 层只需要学"改动量"，原始信号走高速公路直达终点，不会在深处丢失。 The technical point is that the sublayer only has to learn a small residual to add to x, so both the signal and the gradient always have an untouched identity path from input to output.

🎮
Think of the telephone game with 20 people. Whispering down the line garbles the message. But if the first person also texts the message straight to the last person, the last person still has the original — and can fix whatever the whispering broke.
⚠️
Where the analogy breaks: a highway and a town road stay separate, but a residual connection adds the two paths together into one set of numbers. The layer output and the skipped input must have the exact same shape so they can be added element by element.

4Why the +x keeps gradients aliveMechanism & why

Step 1 — in plain words

A residual connection takes the layer's job and splits it in two: the input passes straight through, and the layer only computes a small change to add. In the backward pass, the gradient also gets two roads home. One road goes through the layer. The other road skips straight past it. Even if the layer road is blocked, the skip road always carries the gradient back.

Step 2 — the formula, symbol by symbol

🧮
y = F(x) + x
x = the input to this layer
F = the layer (the "sublayer" — attention or a small MLP)
F(x)= the small change the layer computes
y = the output, same shape as x

Now the backward pass. The gradient of the output y with respect to the input x is:

🧮
dy/dx = F'(x) + 1
F'(x) = the gradient through the layer road
+ 1 = the gradient through the skip road

The +1 is the whole trick. It comes from the + x. It means the gradient can never fully vanish, because there is always at least a "1" passing straight through.

Step 3 — a worked example with small numbers

Suppose the layer road multiplies the gradient by a small number, F'(x) = 0.2. Stack 10 such layers.

  • Without the skip: the gradient is multiplied by 0.2 each time. After 10 layers: 0.2¹⁰ ≈ 0.0000001. It has vanished. Early layers get almost no signal.
  • With the skip: each layer passes 0.2 + 1 = 1.2. After 10 layers: 1.2¹⁰ ≈ 6.2. The gradient stays healthy — early layers still learn.
🪜
Math Ladder — the +1 that saves the gradient
1 · In words: the output is the layer's change plus the untouched input, so the backward gradient has two roads — through the layer, and straight past it (see Steps 1–2).
2 · The formula: y = F(x) + x → dy/dx = F'(x) + 1 — F'(x) = gradient through the layer road; +1 = gradient through the skip road.
3 · Tiny numbers: F'(x)=0.2, 10 layers → plain 0.2¹⁰≈1e−7 (vanished); residual (0.2+1)¹⁰≈6.2 (alive).
4 · Sanity check: F(x) and x must have identical shape to add, and the +1 sets a floor so the gradient can't reach exactly 0. (LayerNorm — next lesson — keeps the other road from exploding.)

Why it matters — before and after

🔗
The big picture: the original ResNet paper (2015) used this exact idea to train networks over 100 layers deep for the first time. Every modern transformer wraps both its attention sublayer and its feed-forward sublayer in a residual connection. Without it, a 96-layer model like GPT-3 could not be trained at all.

The staff lens — one silent failure, one trade-off

The residual add looks like the safest line in the model. But it is exactly the line where a wrong shape can hide instead of crash, and where "just add a skip" quietly costs memory.

⚠️
Failure mode (silent): a broadcast add that does not match. The skip is y = F(x) + x, an element-by-element add that needs F(x) and x to have the exact same shape. If a reshape or a projection leaves them differing on a size-1 axis, PyTorch does not raise an error — it broadcasts the smaller one and adds anyway. The model trains, the loss goes down, but you have quietly mixed the wrong numbers together, and accuracy tops out low for no visible reason. A senior engineer reads the residual line in code review and asserts F(x).shape == x.shape right before the add, because the shapes are what the + silently forgives.
⚖️
Trade-off: trainability now, memory later. The skip gives the gradient a clean road home, which is what lets you stack 96 layers at all. What you pay is memory: the input x must be kept around until the backward pass so the +1 road can be used, so every residual point holds an extra activation in memory. In a design review for a very deep or long-context model this shows up as an activation-memory bill, and it is the reason techniques like activation checkpointing exist — you re-compute the skipped activations later instead of storing them.
🎤
Say this in an interview: "A residual connection is y = F(x) + x — the sublayer only learns the change and the input skips straight through. In the backward pass that gives dy/dx = F'(x) + 1, and the +1 is a gradient road that never multiplies to zero, so you can stack ~96 layers without the early ones starving. The nuance is that F(x) and x must share a shape or the add silently broadcasts the wrong numbers, and the skip costs activation memory — you keep x for the backward pass, which is why very deep models reach for activation checkpointing."
