Module 5a · Represent · Day 4

Assembling theDecoder Block

You have all four pieces now: attention, the feed-forward layer, layer normalization, and residual connections. Today you snap them together into one transformer block — the single unit that gets stacked over and over to make a whole model. It is an assembly line with two stations, each wrapped in a quality check and a bypass lane.

🎯
By the end, you'll be able to: assemble the full decoder block — (LayerNorm → attention → residual) then (LayerNorm → feed-forward → residual) — and trace the data shape flowing through it.
1Two sub-layers, each wrapped the same wayWhat is it
🧭
What this assumes: multi-head attention (M3), the feed-forward layer (Day 3), layer normalization (Day 2), and residual connections (Day 1). Today you connect all four.

What it is

A transformer block (also called a decoder block when it uses causal masking) has exactly two sub-layers:

  1. The attention sub-layer — self-attention, so tokens share information.
  2. The feed-forward sub-layer — the per-token thinking step from Day 3.

Each sub-layer gets the same wrapper

Each sub-layer is wrapped in the same two-part safety kit. Using the modern pre-LN order (Day 2):

🧮
x = x + attention(LayerNorm(x))
x = x + feed_forward(LayerNorm(x))

Read it as: normalize first (calm the numbers), run the sub-layer, then add the input back (the residual highway). Do that once for attention, once for feed-forward. That is the whole block.

The magic: it stacks

The output has the same shape as the input. So you can feed the output straight into another identical block, and another, and another. Stack 12 of them and you have GPT-2 Small. Stack 96 and you have GPT-3. Keep going 👇

😕
为什么这里容易卡住 · Why this trips people up: 四个零件都学过了，但"怎么接线"最容易出错。In plain terms: the pieces are familiar, but the wiring order is where mistakes hide. The one rule that makes it click: normalize a copy, run the sub-layer, and add back the original input — the same pattern twice. Get the "add back the original, not the normalized copy" part right and the block just works.
2An assembly line with checks and bypass lanesIntuition
🏭
Two work stations

Station 1 is the meeting room (attention) where tokens share information. Station 2 is the private room (feed-forward) where each token thinks. The product moves down the line through both.

🛣️
A check and a bypass at each

Before each station, a quality check tidies the numbers (LayerNorm). Around each station, a bypass lane carries the original safely to the far side and merges it back (the residual). If a station adds nothing, the bypass still delivers the input.

In one line: the block is two work stations, each with a tidy-up before it and a bypass lane around it, and the product keeps the same shape so the next block can pick it up.

直觉 / Intuition: 一个模板重复用两次：先归一化、再跑子层、最后把原始输入加回来。 The technical point is that both sub-layers share the identical pre-LN wrapper x = x + sublayer(LayerNorm(x)), and because the shape is preserved, the same block stacks N times to make the whole model.

🎮
Every real transformer is just this one station repeated: 12 times, 24 times, 96 times. Same design, different learned weights in each copy. Learn one block and you understand the whole tower.
⚠️
Where the analogy breaks: on a real assembly line the bypass and the station stay separate, but here the bypass output is added to the station output — one set of numbers, not two. And the "check" (LayerNorm) does not reject anything; it rescales.

4The block in code, shape by shapeMechanism & why

Step 1 — in plain words

Take the sequence of tokens. Sub-layer 1: normalize it, run attention so tokens mix, then add the original back. Sub-layer 2: normalize again, run the feed-forward layer so each token thinks alone, then add its input back. Out comes a sequence with the same shape you started with.

Step 2 — the formula, symbol by symbol

🧮
# sub-layer 1: attention
a = attention(LayerNorm(x))
x = x + a # residual add
# sub-layer 2: feed-forward
f = feed_forward(LayerNorm(x))
x = x + f # residual add
x = the sequence, shape (seq_len, d_model)
seq_len = number of tokens; d_model = size of each token

Every line keeps the shape (seq_len, d_model). LayerNorm does not change shape. Attention returns the same shape. Feed-forward returns the same shape. The residual adds two same-shaped things. So the output matches the input exactly.

Step 3 — a worked example with small numbers

Say seq_len = 3 tokens and d_model = 4. The input is shape (3, 4).

  • LayerNorm(x) → still (3, 4).
  • attention(...) → (3, 4); add back → x is (3, 4).
  • LayerNorm(x) → (3, 4); feed_forward(...) → (3, 4); add back → (3, 4).

Output shape: (3, 4) — identical to the input. Feed it straight into the next block.

🪜
Math Ladder — the pre-LN block
1 · In words: two sub-layers, each wrapped the same way — normalize, run the sub-layer, add the original input back (see Steps 1–2).
2 · The formula: x = x + attention(LayerNorm(x)); x = x + feed_forward(LayerNorm(x)) — x = the sequence, shape (seq_len, d_model); every piece preserves that shape.
3 · Tiny numbers: seq_len=3, d_model=4 → input (3,4) → after sub-layer 1 still (3,4) → after sub-layer 2 still (3,4).
4 · Sanity check: output shape must equal input shape, so blocks compose N deep with no glue. The residual add must use the input from before the norm, not the normalized copy — the silent bug below.

Why it matters — the repeating unit

🔗
The big picture: because the shape is preserved, a transformer is just this one block repeated N times, plus embeddings at the bottom and a projection at the top (Day 8). The block is the "floor" of the tower. The only difference between GPT-2 Small and GPT-3 is how many floors you stack.

The staff lens — one silent failure, one trade-off

The block is where three parts you already learned — LayerNorm, attention, and the residual add — get wired together, and the wiring order is a decision that can go wrong without a single error.

⚠️
Failure mode (silent): adding the normalized copy back instead of the real input. In pre-LN the residual add must use the original x: x = x + attention(LayerNorm(x)). It is easy to write x = LayerNorm(x); x = x + attention(x) instead — now you added the normalized copy back, not the raw input, so the clean residual highway from Day 1 no longer carries the true signal through. Shapes still match, no error appears, but very deep stacks train worse and you cannot see why. A senior engineer in code review checks that the tensor added by the residual is the block's input from before the norm, not the normalized version.
⚖️
Trade-off: the block bundles a cheap part with an expensive one. The two sub-layers do not cost the same. The feed-forward sub-layer runs on each token alone, so its cost grows linearly with the number of tokens. The attention sub-layer lets every token look at every other token, so its cost grows with the square of the sequence length. Stacking the block N times multiplies both. In a design review this is why long context is expensive: doubling the sequence length roughly quadruples the attention work in every block, which is what pushes teams toward tricks like sliding-window or sparse attention.
🎤
Say this in an interview: "A transformer block is two sub-layers — self-attention then a position-wise FFN — each wrapped as x = x + sublayer(LayerNorm(x)) in the pre-LN order. Shape is preserved end to end, so you stack the identical block N times; GPT-2 Small is 12, GPT-3 is 96. The nuance is the residual must add the pre-norm input, not the normalized copy, or the clean gradient highway breaks; and the two sub-layers scale differently — FFN is linear in sequence length, attention is quadratic — so long context is an attention-cost problem."
