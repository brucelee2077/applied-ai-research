x = [10 20 30 40]  shape (4,)  -> positions are 0, 1, 2, 3
indexing:
  x[0]       -> 10            shape ()      copy (own memory)
  x[2]       -> 30            shape ()      copy (own memory)
  x[-1]      -> 40            shape ()      copy (own memory)
  -> an index returns shape () : one single number, and it is a copy of that value

slicing — I predict the length, THEN numpy runs:
  x[1:3] -> I say 3 − 1 = 2 ; numpy gives [20 30]   len 2  match: True
  x[0:2] -> I say 2 − 0 = 2 ; numpy gives [10 20]   len 2  match: True
  x[2:4] -> I say 4 − 2 = 2 ; numpy gives [30 40]   len 2  match: True
  x[0:4] -> I say 4 − 0 = 4 ; numpy gives [10 20 30 40] len 4  match: True
the lesson's three slices:
  x[1:3]     -> [20 30]       shape (2,)    VIEW (shares memory)
  x[:2]      -> [10 20]       shape (2,)    VIEW (shares memory)
  x[::2]     -> [10 30]       shape (2,)    VIEW (shares memory)
  -> the stop is excluded, so x[1:3] has 2 elements, not 3
